=========================================
Instrucciones de instalación y ejecución
=========================================
1. Requisitos previos

Asegúrate de tener Python 3.8 o superior instalado.

2. Instalación de dependencias

Ejecuta los siguientes comandos en tu terminal:

pip install -r requirements.txt

3. Ejecución de la aplicación

Para iniciar el proyecto, ejecuta el archivo principal:

python Main.py

4. Información Adicional

Si no descargas la matriz de correlación no seras capaz de recibir una recomendación.

La valoración de los animes se realiza con ID, se recomienda ver los animes disponibles y su ID antes de valorar.

Debido al tamaño de los datos es posible que a veces el programa tarde un poco en reaccionar.
